gu-videos

个人主页作品集的图片 / 视频图床 · 经 GitHub Pages 提供

本站是 icycal.github.io/personal-homepage 的素材仓库， 不提供页面浏览，仅通过 HTTPS 直接返回媒体文件。 主页的 data.js 以如下格式引用本仓库资源：

https://icycal.github.io/gu-videos/portfolio/<slug>/<file>

目录结构

  • portfolio/xiaodu/ — 儿童手表小度助手（封面 webp + 演示 mp4）
  • portfolio/stethoscope/ — 智能多模听诊器（主图 / 实拍 / 演示 mp4）
  • portfolio/zhuge/ — 诸葛智能体（15 张 webp）
  • portfolio/wifimodule/ — AIDK 物联网平台 · WiFi 模组（4 张 webp）

投放约定

  • 子目录名 = 主页 data.js 里的作品 slug
  • 图片统一 WebP；视频统一 H.264（avc1）yuv420p + faststart
  • 路径保持全 ASCII（中文路径会让 GitHub Pages 编码异常，页面拿不到图）
